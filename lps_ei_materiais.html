Envie aqui as listas de material (que definem a demanda por área) e o Tracker de suprimentos (que traz o que já foi pedido e recebido). Tudo é processado no navegador; nada sobe para o banco até você clicar em Publicar snapshot — que grava o estado atual para a unidade e passa a ser o que todo mundo enxerga.
1 · Listas de material
Listas de solicitação (Aplus / VIA PACS / ON7)
Aceita vários arquivos de uma vez. O layout é detectado automaticamente: Aplus (CÓDIGO + LINE NUMBER), PACS (COD + REFERÊNCIA + LINE NUMBER) ou ON7 (aba LM, área no campo PRÉDIO do cabeçalho, sem line number). No modelo ON7 os itens sem código mapeado — TERCEIRO, omissos — são descartados. Reenviar um arquivo com a mesma TAG substitui a revisão anterior.
2 · Tracker (base de dados)
Arquivo atualizado do Tracker
Um único arquivo. As colunas são reconhecidas automaticamente e você pode corrigir o mapeamento logo abaixo, caso o layout mude.
3 · Mapeamento das colunas do Tracker
Confira cada campo. O Código do material é obrigatório — é a chave que liga o Tracker às listas. Se o Tracker tiver Line Number, o casamento é item a item; sem ele, a quantidade de cada código é rateada entre as áreas proporcionalmente à demanda de cada uma.
